# TaskFlow ⚡

A clean, minimalist Todo app layout.

## 🌟 Highlights
- **Enter-to-Add**: Type any task into the input bar and press <kbd>Enter</kbd> to add it directly to the list.
- **Pure Layout**: Clean and distraction-free — without Add buttons, Complete checkboxes, or Delete actions.
- **Tech Stack**: Built purely using **HTML**, **CSS**, and **JS** (`script.js`).

## 🚀 How to Run
Open `index.html` in any browser, or view via your local server:
```bash
python -m http.server 8080
```
Open `http://localhost:8080` in your browser.
